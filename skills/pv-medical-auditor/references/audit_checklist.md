# SAE 报告审核清单 (Audit Checklist)

逐项快速扫描清单。每份 SAE 报告审核时按顺序过一遍，标记 ✓（通过）/ ✗（命中）/ —（不适用）。

---

## Tier-1：高频核心维度（每份报告必查）

### T0 — 历史质疑闭环核查
- [ ] 当前是否为随访/总结报告？（如是，进入下项核对）
- [ ] 前次报告提出的每一条 Query 是否都在本版得到更正？
- [ ] 跨段落的修改（如修订说明 vs 正文 vs 相关性判断）是否一致且无残留？

### T1 — 转归与源数据一致性
- [ ] 出院病案关键词检查（好转未愈 / 自动出院 / 带药 / 继续治疗）
- [ ] 出院查体是否有残余体征（啰音、肿大、疱疹未消、咳嗽等）
- [ ] 末次检验指标是否恢复正常
- [ ] 转归判定（痊愈/好转）与上述源数据是否一致
- [ ] SAE 结束日期是否合理（≠ 出院日，除非确无残余体征）
- [ ] 若出院后有带药/巩固用药，结束日期是否覆盖用药结束

### T2 — 因果关系论证严谨性
- [ ] 正文是否含绝对化表述（"完全排除""无任何关联""可直接排除"）
- [ ] 研究者定性（可能无关/可能相关）与论证文本是否一致
- [ ] 病原学定性是否有对应的特异性实验室结果支撑
- [ ] 时间超窗（>100天）是否已作为核心证据
- [ ] 潜伏期/前驱症状论证是否充分
- [ ] "接种后第X天"计算是否准确
- [ ] 论据是否针对本病例实际病理（非模板残留）

### T3 — 伴随用药规范性
- [ ] 用药清单是否混入院前自用药
- [ ] 用药清单是否混入出院后带药/院外用药
- [ ] 每项用药指征是否与药理机制匹配
- [ ] 给药途径是否合理（特别关注局麻药、注射剂）
- [ ] 住院核心治疗是否完整记录（静滴/雾化/手术用药）
- [ ] 同一药物是否存在剂量冲突或重复条目
- [ ] 重要非药物干预（洗胃、手术等）是否记录
- [ ] 药名是否有转录错误

### T4 — 病原学/检验依据充分性
- [ ] 因果论据中定性的病原体是否有对应实验室结果
- [ ] 肺炎/支气管炎诊断是否有胸片/CT 支撑
- [ ] 排他性检验（如诺如病毒阴性）是否已纳入论据
- [ ] 炎性指标与论据结论是否一致（如 WBC↑ 但称"不支持感染"）
- [ ] 疑似目标疾病是否触发了标本采集送检流程

### T5 — SAE 事件拆分/合并
- [ ] 同次住院是否存在多个独立 SAE 报告
- [ ] 若有多个 SAE，病程是否连续或病理相关
- [ ] 同一解剖区域的多个诊断是否被拆分
- [ ] 主/次 SAE 的设定是否合理（主要住院指征 = 主 SAE）

---

## Tier-2：条件触发维度

### T6 — 基线病史漏记与 PD 风险
- [ ] 现病史/入院记录中的既往史是否已录入基线病史表
- [ ] 既往史是否涉及方案排除标准（恶性肿瘤、免疫疾病等）
- [ ] 入组前已确诊的疾病是否可能违反入排标准
- [ ] 入组时受试者是否可能已有活动性症状
- [ ] 特殊感染指标（如梅毒抗体阳性）是否已正确评估和记录
- [ ] 是否需要上报 PD

### T7 — 时序逻辑自洽性
- [ ] SAE Onset Date 是首发症状日还是入院日（方案定义优先）
- [ ] 用药指征是否前置于确诊日期（ALCOA+ 违背）
- [ ] 有无年份/日期笔误（如 2028→2026、20226→2026）
- [ ] 接种日期与剂次编号是否匹配
- [ ] 既往史中的时间描述是否前后一致
- [ ] 转归日期/事件结束日期是否与源数据对齐

### T8 — 诊断准确性 / MedDRA 编码
- [ ] PT 编码特异度是否足够（未被上位词泛化）
- [ ] 是否存在 Down-coding 风险（如自杀企图→中毒）
- [ ] 收治科室与 SAE 诊断是否逻辑匹配
- [ ] 因果论述中的病理主体与 SAE 诊断是否一致
- [ ] 老年性/慢性疾病的 onset date 是否合理

### T9 — 研究者/申办者相关性不一致
- [ ] 是否存在研究者与申办者判定不一致
- [ ] 若不一致，是否建议更新不一致清单

---

## Tier-3：专项/特殊场景

### T10 — 既往症择期手术 SAE 合理性
- [ ] 疾病是否始于入组前且近期无明显加重
- [ ] 手术是否为择期安排
- [ ] 是否满足 SAE 报告标准
- [ ] 若不满足，是否建议撤销并转入既往史记录

### T11 — 住院合理性/医疗必要性
- [ ] 轻微诊断（如擦伤）是否长期住院
- [ ] 关键检查（GCS、影像）是否支持住院指征
- [ ] 是否可能为非医疗目的住院（理赔/观察）

### T12 — 文本质控与笔误
- [ ] 药名/医学术语是否有错别字
- [ ] 物理单位是否正确（mm vs nm）
- [ ] 年份/日期是否有笔误
- [ ] 是否存在模板残留文字
- [ ] 是否存在重复文字或重复条目
- [ ] 修订说明与正文实际内容是否对应
- [ ] 瞳孔/体征记录格式是否统一
