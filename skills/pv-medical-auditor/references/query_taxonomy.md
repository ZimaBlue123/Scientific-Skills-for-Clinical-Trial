# Query 分类学与判定规则 (Query Taxonomy & Judgment Rules)

本文档为 `pv-medical-auditor` Skill 的核心参考文件，定义每个审核维度的判定规则、命中信号与常见模式。

---

## T0 — 历史质疑闭环核查 (Historical Query Resolution)

### 判定规则
1. 若当前报告为随访报告或总结报告，必须扫描上一个版本的 Query 内容。
2. 逐一对照原 Query 中指出的数据冲突、错误描述等，核实当前报告中是否已**全部且一致地**进行了更正。
3. 特别关注“跨段落更新不全”（如：修订说明已改，但相关性判定部分或源文仍保留旧表述）。
4. 若存在未更正的遗留问题，立即提出复核。

### 命中信号词
`前次Query` `遗留` `未完全修正` `错配未改`

### 常见 Query 模式
- 文本错配未改：前次要求修正诊断表述，但部分段落仍遗留旧主体表述。
- 问题悬而未决：前次 Query 要求提供某指标，本次随访仍未提供且无说明。

## T1 — 转归与源数据一致性 (Outcome vs. Source Data)

### 判定规则
1. 若出院病案包含以下任一关键词，转归**不得**为"痊愈/症状消失"：
   - "好转未愈"、"好转出院"、"自动出院"、"带药出院"、"继续治疗"
2. 若出院查体/末次检查存在以下任一残余体征，转归应为"好转"：
   - 肺部：啰音未消、偶有咳嗽
   - 肝脏：肝肋下可触及、ALT/AST 偏高
   - 皮肤/黏膜：疱疹/皮疹基本消退但未完全消失
   - 其他：残余发热、纳差、残留体征
3. 若转归为"痊愈"，结束日期必须与以下之一对齐：
   - 末次随访确认症状完全消失的日期
   - 末次实验室指标恢复正常的日期
4. 出院日 ≠ 痊愈日（除非方案有特殊定义且出院时确无残余体征）

### 命中信号词
`好转未愈` `自动出院` `带药` `仍有` `偶有` `基本消退` `轻度偏高` `尚未恢复` `继续服药` `巩固用药`

### 常见 Query 模式
- 出院病案"好转未愈" + 转归"痊愈" → 建议调整为"好转"
- 出院后带药/巩固用药 + SAE 结束日 = 出院日 → 建议延后结束日期
- EB 病毒感染肝脾肿大恢复需数周 + 出院即判"痊愈" → 医学逻辑错误

## T2 — 因果关系论证严谨性 (Causality Logic)

### 判定规则
1. **绝对化表述检测**：正文出现以下表述时，与"可能无关"的定性矛盾：
   - "完全排除"、"无任何直接关联"、"可直接排除"
   - → 应调整为"现有临床证据未提示与试验疫苗存在直接的病理生理学关联"
2. **靶标对齐**：
   - 因果论据必须针对本病例的实际病理诊断
   - 若已实验室排查某病原体（如支原体阴性），论据不可仍残留"无诱发支原体"等模板抗辩
3. **病原学过度定性**：
   - 若无特异性实验室结果支持 → 禁止直接定性"肠道病毒（柯萨奇A组病毒、EV71型等）"
   - → 应回调为"临床考虑外源性病毒感染所致"或"病原微生物感染"
4. **时间超窗论据**：
   - 接种后 >100 天发病 → 时间超窗应作为支持无关的核心证据
   - 接种当日发热 → 潜伏期规律提示暴露发生于接种前
5. **Onset 日计算错误**：
   - "接种后第 X 天"的计算需核实是否准确（如将入院日误记为起病日）

### 命中信号词
`完全排除` `无任何关联` `可直接排除` `肠道病毒` `柯萨奇` `肺炎支原体`（无检验时）`接种后第X天`（需验算）

### 常见 Query 模式
- 论据绝对化 + 定性"可能无关" → 建议调整措辞
- 定性"肺炎支原体"但无化验 → 建议回调为"病原微生物感染"
- 接种后 102 天发病 → 应突出时间超窗作为核心证据
- "接种后第46天"误算 → 建议修正为首发症状时间

## T3 — 伴随用药规范性 (Concomitant Medications)

### 判定规则
1. **时限属性混淆**：
   - 住院用药清单中出现入院前院外自用药 → 要求剥离至"入院前合并用药"
   - 住院用药清单中出现出院后带药/院外用药 → 要求剥离至"出院带药"
2. **适应症/药理不符**：
   - 抗组胺药（氯苯那敏）→ 感染性腹泻 ✗
   - 抗生素 → 混合痔（非感染性手术）✗
   - 麻醉剂/局麻药 → 机械归因于原发疾病 ✗
   - 阿司匹林/氯吡格雷 → 脑出血（禁忌证）✗ → 需核查诊断
   - 抗血小板药 → 高血压/下肢静脉血栓 ✗ → 应为支架术后
3. **给药途径错误**：
   - 利多卡因在局部手术中 → "静脉注射"应为"局部浸润"或"阻滞麻醉"
4. **核心治疗缺失**：
   - 肺炎/支气管炎住院 ≥3 天 → 仅见口服退热药 → 追问静滴/雾化抗感染治疗
   - 手术住院 → 缺失麻醉用药、抗生素预防、镇痛药
5. **剂量/记录冲突**：
   - 同一药物同一时间段出现两种不同剂量
   - 用药清单条目完全重复
6. **非药物干预遗漏**：
   - 洗胃及所用溶剂未记录
   - 手术操作（如碘125粒子植入）住院用药为"不详"
7. **转录错误**：
   - "中医重洗"→"中药熏洗"、"获苓"→"茯苓"、"枯梗"→"桔梗"、"甘单"→"甘草"、"蝉脱"→"蝉蜕"
   - "小儿咽扁颡粒"→"小儿咽扁颗粒"

### 命中信号词
`出院后` `入院前` `静脉注射`（局麻药）`用药原因` `适应症` `给药途径` `不详` `重复`

## T4 — 病原学/检验依据充分性 (Pathological Evidence)

### 判定规则
1. 因果论据或诊断定性了具体病原体，但全文无相应特异性检验 → 建议回调
2. 住院诊断为肺炎/支气管肺炎但无胸片/CT → 要求补充或注明"基于体征综合拟诊"
3. 排他性证据：若诺如病毒核酸检测阴性 → 应作为核心排他性证据纳入因果论据
4. WBC/CRP 显著升高 + 抗感染治疗 → 正文称"不支持细菌感染"存在矛盾
5. 疑似目标疾病（如急性胃肠炎）→ 核查是否触发了标本采集与送检流程

### 命中信号词
`肠道病毒` `肺炎支原体` `柯萨奇` `EV71`（无对应检验时）`未行影像` `未见化验`

## T5 — SAE 事件拆分/合并 (Splitting vs. Merging)

### 判定规则
1. **同次住院 + 病程连续**：
   - 上呼吸道感染（咽峡炎）→ 下蔓延 → 肺炎 = 高度病理相关 → 合并
   - 主要住院指征应设为主 SAE，其余为并发症
2. **同一解剖区域**：
   - 混合痔 + 肛门狭窄 + 直肠粘膜脱垂 = 同区域 → 合并为"混合痔"
3. **同一病因/事件**：
   - 同一交通事故导致的多处擦伤 → 合并为单一外伤事件
   - EB 病毒感染导致的扁桃体炎+肝脾肿大 → 主诊断为传染性单核细胞增多症
4. **拆分风险**：
   - 同次住院拆分为多个独立 SAE → Double-counting 风险 → 影响安全性信号评估

### 命中信号词
`同次住院` `两份SAE` `并发症` `伴随症状` `连续病程` `同一解剖`

## T6 — 基线病史漏记与 PD 风险 (Baseline & Protocol Deviation)

### 判定规则
1. **基线漏记**：
   - 现病史/入院记录提及的既往慢病（如高血压2-3年、痔疮病史、子宫腺肌病）
   - 比对基线《既往病史表》→ 缺失 → 要求补充
2. **入排穿透/重大 PD**：
   - 恶性肿瘤（转移性恶性黑色素瘤、胰腺癌等） → 明确不适合参研
   - 慢性免疫/皮肤病（特应性皮炎反复发作 8 年）→ 核查排除标准
   - 糖尿病（入组前可能已达诊断标准）→ 核查是否构成 PD
   - 入组前数月即有活动性症状（"咳嗽1月余"覆盖接种日）→ 基线体检冲突
3. **既往手术史遗漏**：
   - 病历提及多年前手术史但基线未记录
4. **梅毒等特殊感染指标**：
   - 梅毒抗体阳性 → 需区分"既往感染"vs"现症感染"→ 影响入排判定

### 命中信号词
`既往` `病史` `入组前` `排除标准` `方案偏离` `PD` `基线` `未记录`

## T7 — 时序逻辑自洽性 (Temporal Logic)

### 判定规则
1. **Onset Date**：
   - 若方案明确规定入院为开始 → 尊重方案
   - 若未规定 → 首发症状日应为 onset date，非入院日
   - 实体瘤：onset date 应为首次客观医学证据日期（影像/病理确诊日）
2. **用药指征前置（ALCOA+ 违背）**：
   - 确诊日前开具的药物指征不得回填该确诊诊断
   - 如：流感 07/08 确诊，07/01-07/06 用药指征不能写"流行性感冒"
3. **日期/年份笔误**：
   - "2028年" → "2026年"
   - "20250226" → "20260226"（跨年错误）
4. **接种剂次与日期对应**：
   - 核算接种日与剂次编号是否匹配（如 04-13 接种应为第三剂而非第二剂）
5. **既往史时间逻辑**：
   - "高血压病史2-3年"但起病年份距今 6-7 年 → 矛盾
   - "2019年用药至2020年停药"但正文写"平素口服" → 矛盾
6. **转归日期与源数据冲突**：
   - 化脓性扁桃体炎转归日 vs 源数据脓点消失日 / 查体无肿大日

### 命中信号词
`开始日期` `结束日期` `接种后第X天` `确诊日` `发病时间` `既往X年`

## T8 — 诊断准确性 / MedDRA 编码 (Coding Precision)

### 判定规则
1. **PT 特异度降级**：
   - "支气管肺炎" → 编码至"PT：感染性肺炎" ✗ → 应为"PT：支气管肺炎"
2. **Down-coding 风险**：
   - "蓄意自伤/自杀企图" → 降级为"消毒剂中毒" ✗（参考 MedDRA IME List）
   - "抑郁发作"属于 IME，不得以"未达SAE标准"排除
3. **收治科室 vs 诊断矛盾**：
   - 皮肤擦伤 → 收治神经外科 → 提示可能存在颅脑损伤
4. **正文论述主体漂移**：
   - SAE 诊断"支气管肺炎"但因果论述中变成"支气管炎" → 不一致
5. **既往疾病 vs 新发事件**：
   - 长期病史入组期间择期手术 → 事件性质应为"既往疾病加重"或"择期手术"
6. **老年性白内障 onset 矛盾**：
   - 慢性退行性疾病不应在急性事件日（化学烧伤日）发病

### 命中信号词
`PT` `MedDRA` `编码` `诊断` `科室` `收治` `IME`

## T9 — 研究者/申办者相关性不一致 (Causality Disagreement)

### 判定规则
1. 当研究者与申办者对 SAE 因果关系判定不一致时 → 固定输出：
   - "相关性判定不一致，建议更新'研究者与申办者评价不一致的SAE清单'，以供研究者参考"
2. 若医学证据充分支持降级（如器质性病因 + 超长时间跨度）→ 建议研究者重新评估

### 触发条件
- 报告中明确记录研究者判定与申办者判定存在差异
- 用户提示存在不一致

## T10 — 既往症择期手术 SAE 合理性 (Elective Surgery)

### 判定规则
1. 确认疾病始于入组前且近期无明显加重
2. 确认手术为择期安排（"因个人时间许可选择手术"）
3. 满足以上两条 → 建议撤销 SAE 报告，记录于既往史/合并疾病
4. 若存在急性加重 → 要求补充具体恶化指征及起始时间

### 命中信号词
`择期` `选择手术` `近期无加重` `个人时间许可` `既往X年`

---

## T11 — 住院合理性/医疗必要性 (Hospitalization Justification)

### 判定规则
1. GCS 正常(15分) + 头颅 CT 无异常 + 仅擦伤 + 住院 >7 天 → 质疑
2. 可能原因：交通事故理赔/医学观察 vs 纯粹医疗必要性
3. 若研究者坚称"病情危重" → 建议合并诊断并调整 SAE 术语

### 命中信号词
`GCS` `CT无异常` `仅擦伤` `住院X天` `理赔`

---

## T12 — 文本质控与笔误 (Text QC)

### 判定规则
1. **药名/医学术语错别字**：
   - 获苓→茯苓、枯梗→桔梗、甘单→甘草、蝉脱→蝉蜕、部疹→疱疹
   - 小儿咽扁颡粒→小儿咽扁颗粒
2. **单位错误**：3.0nm / 3.0mn → 3.0mm
3. **年份笔误**：2028年→2026年、20226年→2026年
4. **模板残留**：
   - "支气管肺炎另做SAE" 残留于不相关字段
   - 修订说明与正文实际更新内容不对应
5. **重复文字**：
   - "结合结合"
6. **用药清单重复条目**：
   - 同一药物、同一时段、完全相同的两行记录
7. **瞳孔记录**：
   - 入院 vs 出院记录中单位/格式不一致
8. **首句重复**：
   - 判定首句重复显示

### 命中信号词
任何疑似错别字、不规范单位、不合理年份、重复内容
