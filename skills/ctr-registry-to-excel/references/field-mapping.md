# CTR 登记文档 → Excel 列映射

## 1. CTR 导出文档（.doc）的固定字段布局

从 CTR 登记平台导出的「XXX详细信息.doc」结构固定，按段落顺序出现：

| 区块 | 关键字段 |
|---|---|
| 页首 | 登记号、试验状态、申请人联系人、**首次公示信息日期**、申请人名称 |
| 一、题目和背景信息 | 登记号、相关登记号、**药物名称**（可能带「曾用名:xxx」）、药物类型、适应症、试验专业题目、方案编号 |
| 三、1 试验目的 | 主要/次要目的（**不要**用来填终点列，只作判断依据） |
| 三、2 试验设计 | 试验分类、**试验分期**、**设计类型**、**随机化**、**盲法**、试验范围 |
| 三、3 受试者信息 | **年龄**、性别、健康受试者、入选/排除标准 |
| 三、4 试验分组 | **试验药**表（序号/名称/用法：剂型、规格、用法用量、用药时程）、**对照药**表 |
| 三、5 终点指标 | **主要终点**表（序号/指标/评价时间/终点指标选择）、**次要终点**表 |
| 六、试验状态 | **目标入组人数**、**第一例受试者入组日期**、**试验完成日期** |

## 2. 字段 → 列映射（以带疱疫苗 15 列库为例，仅作示例）

| Excel 列 | 来源 | 抽取要点 |
|---|---|---|
| A 申请人 | 页首「申请人名称」 | 多家用 `/` 连接，不加空格 |
| B 制品名称 | 「药物名称」 | 砍掉「曾用名:xxx」，只留主干 |
| C 登记号 | 页首「登记号」 | **主键**，匹配与排序都靠它 |
| D 研究分期 | 「试验分期」 | 「其它IIIb」→ `IIIb期`；「其它I/II期」→ `I/II期`；「其它对照试验」照录 |
| E 试验设计 | 随机化 + 盲法 + 设计类型 | 三段用顿号拼：`随机化、双盲、平行分组` |
| F 主要人群（例） | 「年龄」 | 用 Word 原文：`40岁(最小年龄)至无上限(最大年龄)` |
| G 样本量 | 「目标入组人数」 | 取 `国内: N 人` 的 N；「登记人暂未填写该信息」→ 留空 |
| H 试验组 | 试验药表 | `1）名称` + 换行；同上药不同剂量时加 `（0.25 mL/剂）` 区分 |
| I 对照组 | 对照药表 | 安慰剂、氯化钠注射液，**以及已上市竞品**（欣安立适/SHINGRIX、感维） |
| J 免疫程序 | 用药时程 | `2剂（0，2月）` / `2剂（0，60天）` / `共接种2次，第0月（研究第0天）、第2月（研究第60天）` |
| K 主要终点 | 主要终点表 | `序号.指标名` + 换行 + `评价时间` |
| L 次要终点 | 次要终点表 | 同上 |
| M 首次公示 | 页首「首次公示信息日期」 | 日期型 |
| N 首例入组 | 「第一例受试者入组日期」 | 未填写 → 留空（勿用签署知情同意书日期替代） |
| O 试验完成 | 「试验完成日期」 | 未填写 → 留空 |
| P 备注 | — | 试验状态等非日期信息（如「主动暂停（没有市场）」）放这里，**不要塞进日期列** |

## 3. 行文风格（照库内既有数据，不要自创）

```
试验组/对照组:   1）重组带状疱疹疫苗（CHO细胞）
                 2）重组带状疱疹疫苗（CHO细胞）（复溶后0.5 mL/剂）

免疫程序:        2剂（0，2月）

主要/次要终点:   1.抗gE抗体几何平均浓度（GMC）
                 全程免疫后30天
                 2.抗gE抗体阳转率
                 全程免疫后30天
```

注意：**试验组/对照组列在既有库里是纯药名列表**（46 行 0 条带剂型规格）。
只有在同一药品需要按剂量/批次区分时才加括号后缀。

## 4. 新增 / 补全 / 修正 / 未动 的判定

| 情况 | 判定 | 动作 |
|---|---|---|
| 登记号在库中不存在 | 新增 | 追加整行，风格照库内，样式克隆模板行 |
| 单元格空、源文档有值 | 补全 | 写入 |
| 单元格有值、与源文档不符 | 修正 | **以源文档为准覆盖** |
| 源文档标注「登记人暂未填写该信息」 | 修正（清空） | 清空，哪怕原格有值 |
| 单元格与源文档一致，或两边都空 | 未动 | 不动 |

> 人工录入的日期是重灾区：曾出现把 2023 年登记的试验写成 2020-02-18、
> 2025-04-25 的情况。**凡登记号年份与日期年份矛盾，一律以 Word 为准纠正。**
