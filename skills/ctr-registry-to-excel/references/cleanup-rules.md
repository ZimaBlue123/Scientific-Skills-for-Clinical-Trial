# 清洗与全表格式统一规则

分两层：**录入前清洗**（源文本 → 记录值）和**写入时统一**（全表归一化）。
第二层只能做语义无损的替换，否则会毁掉人工补录的信息。

## 1. 录入前清洗（源文本 → records.json）

| 现象 | 规则 |
|---|---|
| `CHO 细胞` / `CHO细胞 ` / 断行成两截 | 统一为 `CHO细胞` |
| `&reg;` `&REG;` | 统一为 `®`（商品名「欣安立适®（SHINGRIX）」） |
| `重组带状疱疹疫苗（CHO细胞）  曾用名:xxx` | 只取主干，砍掉「曾用名」及其后内容 |
| 导出时数字与单位之间多空格（`全程接种30 天后`） | 去掉多余空格 |
| 重复片段（`GMCGMC` `ZBPIZBPI` `PHNPHN`） | 去重为单次 |
| 全角/半角括号混用（`(CHO细胞)`） | 统一全角 `（CHO细胞）` |

## 2. 写入时全表统一（脚本 `normalize_cell`，语义无损）

| 列（按列名关键字匹配） | 规则 |
|---|---|
| 日期类（列名含 日期/公示/入组/完成/启动） | 占位符 `未登记` `暂未填写` `暂无` `—` `-` → 清空 |
| 申请人 / 申办 | 去掉 `/` 两侧空格 |
| 名称 / 制品 / 药物 | 半角括号 → 全角；`CHO 细胞` → `CHO细胞` |
| 分期 | 全角罗马 `Ⅰ/Ⅱ期` → 半角 `I/II期` |
| 设计 | 段首 `随机、` → `随机化、`；`非随机、` → `非随机化、` |

**禁止在没有源文档时凭空统一的项目**：

- ❌ 主要人群：`40岁以上人群` 与 `40岁(最小年龄)至无上限(最大年龄)` 两种写法，
  无 Word 就无法判断，改了就是造假。
- ❌ 试验设计第三段：`随机、双盲、安慰剂对照` 里的「安慰剂对照」是**人工补录的
  对照信息**，Word 的「设计类型」字段只有「平行分组」。若整体改成
  `随机化、双盲、平行分组` 会丢信息 —— 只规范前两段。
- ❌ 终点指标：无源文档不得改写条目数与措辞。
- ❌ 免疫程序：不同试验的给药时程不同，无源文档不得套用统一模板。

## 3. Excel 写入层规则

1. **重排必须快照样式**：`value + copy(cell._style) + row_dimensions.height`，
   排序后整体回写，否则格式全丢。
2. **内容变长的行把 height 置 None**：交回 Excel 自动行高，沿用旧固定行高会截断。
3. **补日期强制 `number_format = yyyy-mm-dd`**：填进原本空白的格子会继承
   "General"，显示为序列号（如 45053）。
4. **同步 `auto_filter.ref`**：行数变化后必须更新为 A1:{末列}{末行}。
5. **新增行样式克隆模板行**（默认第 2 行），保证字体/换行/日期格式一致。
6. 交付前跑 `verify_ctr_excel.py`；**不要**用 present_files 预览交付的 Office 文件
   （预览实例会持独占锁，用户本地打开会报「被另一用户锁定」）。
