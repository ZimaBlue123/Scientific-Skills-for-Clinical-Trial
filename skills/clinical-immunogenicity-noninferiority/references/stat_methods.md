# 统计口径与公式

本 skill 的统计实现全部在 `scripts/compute_noninferiority.py`，纯标准库、无第三方依赖，
便于审计与复现。下面列出每项方法的口径、边界条件与常见变体。

## 1. 单组率 95%CI：Clopper-Pearson

精确二项置信区间（与 Beta 分位数的等价形式）：

- 上限：`BetaInv(1 − α/2, x + 1, n − x)`
- 下限：`BetaInv(α/2, x, n − x + 1)`
- 边界：`x = 0` 时下限取 0；`x = n` 时上限取 100（%）或 1（比例）

疫苗行业惯例；不要用 Wald（正态近似）法，小样本下会给出负的下限。

## 2. 组间率差 95%CI：Miettinen-Nurminen

率差 `d = p1 − p2`（百分点）。在约束 `p1 − p2 = d` 下求约束 MLE，
构造分数统计量 `Z(d)`，用二分法解 `Z(d) = ±z_{1−α/2}`。

**必须带小样本校正** `var ×= (n1 + n2) / (n1 + n2 − 1)`，否则与 TFL 官方值对不上。

实现要点：

- 约束 MLE 用黄金分割一维最大化（比 Newton 稳，边界不会跑飞）
- `_loglik` 在参数越界时返回 `-1e18`，避免 `log(0)`
- `d` 的搜索区间取 `(−0.999999, 0.999999)`，二分 200 次

## 3. 交叉验证：Newcombe 杂交 Wilson

原理：先分别算两组的 Wilson CI `(l1, u1)`、`(l2, u2)`，再杂交：

```
diff = p1 − p2
下限 = diff − sqrt((p1 − l1)² + (u2 − p2)²)
上限 = diff + sqrt((u1 − p1)² + (p2 − l2)²)
```

用途：**独立实现**用于交叉验证。与 MN 的下限/上限差异通常 <1 个百分点。
若两者差异突大，说明 MN 的约束 MLE 收敛失败或输入有错。

## 4. 组间率检验

- 期望频数 <5 或有 0 格 → **Fisher 确切概率法**（双侧，取所有 `Pr ≤ Pr(observed)` 的表求和）
- 否则可用卡方；本 skill 统一走 Fisher，避免在同一份交付稿里混用两种口径

## 5. 几何均数 GMC 与 95%CI

```
lnGMC = mean(ln xi)
GMC   = exp(lnGMC)
95%CI = exp( lnGMC ± t(0.975, n−1) × SD(ln x) / sqrt(n) )
```

- 非正值的处理见第 8 节（删失值）
- `n < 2` 时无法估计标准差，返回 `(GMC, None, None, n)`

## 6. GMC 比值与 95%CI：对数转换后成组 t 检验

```
diff = mean(ln x1) − mean(ln x2)
sp²  = ((n1−1)s1² + (n2−1)s2²) / (n1 + n2 − 2)
SE   = sqrt( sp² × (1/n1 + 1/n2) )
ratio = exp(diff)
95%CI = exp( diff ± t(0.975, df) × SE )，df = n1 + n2 − 2
P    = 2 × (1 − T_cdf(|diff| / SE, df))
```

**为什么用这个口径**：这是 CSR/SAR 中「经对数转换的成组 t 检验」的标准形式，
可以直接用**官方已发表的组间 P 值**反向验证实现是否正确——这是最强的校准证据
（见下方第 9 节）。

常见变体与取舍：

| 变体 | 何时用 | 代价 |
|---|---|---|
| 成组 t 检验（本 skill 默认） | 与官方 CSR 口径对齐 | 不校正基线不均衡 |
| ANCOVA 校正免前基线 | 基线明显不均衡时做敏感性分析 | 与官方 P 值口径不同，需单独标注 |
| Welch t 检验 | 两组方差相差悬殊 | 多数 SAP 不采用 |

若同时需要，把 ANCOVA 结果作为**敏感性分析**另列，主表仍用成组 t 检验，便于对账。

## 7. 事件类型（指标定义取自 CSR 9.5.3 节）

以 cutoff = 10 mIU/mL、fold = 4 为例：

| event | 定义 | 适用人群 | CSR 名称 |
|---|---|---|---|
| `positive` | 免后 ≥ cutoff | 任意 | 抗体阳性率 |
| `seroconversion` | 免前 < cutoff 且免后 ≥ cutoff | 免前阴性人群 | 阳转率 |
| `fourfold` | 免前 ≥ cutoff 且免后/免前 ≥ fold | 免前阳性人群 | 4 倍增长率 |
| `seroconversion_or_4fold` | 按免前状态二选一 | 全人群 | 阳转（4 倍增长）率 |

注意：**免前阴性人群里的「阳转（4 倍增长）率」在数值上等同于「阳转率」**
（该人群内不存在「免前阳性」分支）。做免前阴性人群分析时不必重复列两个指标。

cutoff 与 fold 在 spec 里可配（`cutoff`、`fold`），不同品种/不同检测方法可能有别的取值，
不要写死。

## 8. 删失值（低于检测限）

清单里常出现 `<2.00`、`＜2.00`（注意全角/半角都可能出现在中文文档里）。
可选规则：

| rule | 取值 | 备注 |
|---|---|---|
| `lod_half` | `LOD / 2` | **默认**；多数疫苗 SAP 与统计分析报告的做法 |
| `lod` | `LOD` | 保守；会把 GMC 抬高 |
| `lod_sqrt` | `sqrt(LOD × 1)` | 少见 |

**必须用法定的官方基线 GMC 反算来确定取哪个规则**（见 SKILL.md Step 5），
不能因为「以前都这么用」就定。

高于检测限的值（`>xxx`）通常**直接取该上限值**参与计算，并在说明页注明。

## 9. 为什么要用「组间 P 值」来校准

三条理由：

1. P 值对实现细节极敏感：方差用 pooled 还是 Welch、是否做过其他校正，
   一改就对不上；能对上说明整套链路（含自由度处理）一致。
2. 它不依赖修约位数：不像 GMC 那样会被保留几位小数影响。
3. 官方汇总表里通常都会给出组间 P 值，随手可得。

TVAX-009B Ⅰ期实测：

| 人群 | 分析集 | 官方 P | 本实现 P |
|---|---|---|---|
| 全人群 | FAS | 0.5066 | 0.5066 |
| 全人群 | PPS2 | 0.5440 | 0.5440 |
| 免前阴性 | FAS | 0.1696 | 0.1696 |
| 免前阴性 | PPS2 | 0.2048 | 0.2048 |

## 10. 数值修约

依 SAP 惯例：

- 率、率差及其 CI：2 位小数
- GMC、GMC 比值及其 CI：3 位小数
- P 值：≥0.0001 保留 4 位；<0.0001 记为 `<0.0001`

**先算后修约**：修约只发生在写 Excel 这一步，`results.json` 保留完整精度，
否则交叉自检会因浮点误差误报。
