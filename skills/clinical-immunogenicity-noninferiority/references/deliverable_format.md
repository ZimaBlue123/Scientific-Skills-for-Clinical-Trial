# Excel 交付稿版式规范

`scripts/build_noninferiority_workbook.py` 生成的交付稿沿用 TVAX-009B Ⅰ期 /
TVAX-009-002 Ⅱ期两版的版式。改版式时以本文件为准。

## 1. Sheet 结构

```
00_说明    单列（A 列），每行一段，宽度 150 字符，自动折行
01_汇总    10 列，全部「人群 × 分析集 × 指标」一行一个判定
比较N_...  13 列，每个「人群_指标」一页，分析集各一行
```

sheet 命名约束（openpyxl 会报错，脚本已做清洗）：

- ≤ 31 字符
- 不含 `/ \ * ? : [ ]`
- 脚本自动处理重名与截断，**全角括号（）与空格是允许的**（比较页名里的
  「抗-HBs阳转（4倍增长）率」因此得以保留）

## 2. `00_说明` 的八节（不可少、不可重排）

脚本按此顺序组装，其中 1/5/6/7 节部分由 `auto_*` 函数按结果自动生成，
2/3/4/8 节由 spec 的 `narrative` 提供：

| 节 | 生成方式 | 必须包含 |
|---|---|---|
| 【核心结论速览】 | 自动生成 | 每组指标的 n/N、率/估计量、CI、判定；末尾一句「不成立的解释」 |
| 【一、分析目的】 | narrative.purpose | 是否为探索性再分析 |
| 【二、数据来源】 | narrative.data_source | 清单表名、汇总校准基准、缺失数据处理方式 |
| 【三、人群与组别】 | narrative.arm_definitions | 两组名称与接种程序、亚人群划分依据 |
| 【四、时点口径】 | narrative.timepoint_note | 时点在各组落在哪个访视、可比性论证 |
| 【五、统计方法与非劣效判定】 | 自动生成 | 各指标方法、界值、判定规则、修约位数 |
| 【六、与官方发表值的校准】 | 自动生成 + calibration_notes | 逐项吻合情况；勘误排查清单 |
| 【七、最终结论与依据】 | 自动生成 + interpretation | 点估计量级、CI 宽度、天花板效应、依据链 |
| 【八、局限性说明】 | narrative.limitations | 探索性、未做多重性调整、基线不均衡等 |

**占位符零容忍**：自检脚本会扫描 `TODO / XXX / 待填 / placeholder`，命中即 FAIL。

## 3. `01_汇总` 列

| 列 | 内容 |
|---|---|
| A 人群 | 免前阴性人群 / 全人群 |
| B 指标 | 抗-HBs阳转率 / 抗-HBs阳转（4倍增长）率 / 抗-HBs GMC |
| C 分析集 | PPS2 / FAS（按 spec.analysis_sets 顺序） |
| D 试验组 | 率指标写 `n/N（xx.xx%）`；GMC 写 `N=xx，GMC x.xxx` |
| E 对照组 | 同上 |
| F 估计量 | 率差（%）或 GMC 比值 —— 表头写明「估计量（率差%／GMC比值）」 |
| G/H 95%CI 下限/上限 | |
| I P 值 | 率差用 Fisher；GMC 比值用成组 t 检验 |
| J 非劣效判定 | 成立 / 不成立 |

列宽：A 16、B 24、C–F 20、G–J 12。

## 4. 比较页布局

```
第 1 行   标题：人群｜指标（试验组 vs 对照组，时点）
第 2 行   副标题：人群 / 指标 / 界值 / 两组说明
第 3 行   比较说明（spec.compare_desc）
第 7 行   分组表头：B:E 试验组　F:I 对照组　J:M 组间比较
第 8 行   列名
第 9 行起 分析集各行（按 spec.analysis_sets 顺序）
末行      判定规则长句
```

率指标列名：

```
分析集 | n/N | 率(%) | 95%CI下限 | 95%CI上限 | n/N | 率(%) | 95%CI下限 | 95%CI上限 | 率差(%) | 95%CI下限 | 95%CI上限 | 非劣效判定
```

GMC 列名：

```
分析集 | N | GMC | 95%CI下限 | 95%CI上限 | N | GMC | 95%CI下限 | 95%CI上限 | GMC比值 | 95%CI下限 | 95%CI上限 | 非劣效判定
```

样式约定：

- 边框：细框 `#BFBFBF`（全表，含空表头区除外）
- 第 7/8 行：`F2F2F2` 填充 + 加粗 + 居中 + 自动折行
- 数据行：居中，不填充
- A 列宽 10，其余列宽 12
- 判定规则行：行高 46，左对齐，跨 B:M 合并

## 5. 为什么判定页不列 P 值

二期两份交付稿的比较页都只到「非劣效判定」为止，P 值集中在汇总页。
一致性优先：**P 值只在 01_汇总 出现**，避免读者在不同页看到不同位数的同一数值。

## 6. 自检脚本依赖的隐含约定

改版式时注意别破坏这些前提（`scripts/selfcheck_output.py` 硬依赖）：

1. 汇总页数据从第 3 行开始，且 A 列非空即视为有效行
2. 比较页数据从第 9 行开始，A 列为分析集名
3. 比较页第 8 行第 3 列是 `率(%)` 或 `GMC`（脚本据此判断该页是率还是 GMC）
4. GMC 页每组占 4 列：`N / GMC / 下限 / 上限`；率页占 4 列：`n/N / 率 / 下限 / 上限`
5. 判定结果文本只能是 `成立` 或 `不成立`
