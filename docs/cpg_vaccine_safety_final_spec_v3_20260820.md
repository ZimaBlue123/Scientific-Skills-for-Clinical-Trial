## 二、检索范围与试验标识（双域覆盖，国内外并重）

### 2.1 疫苗范围（预防性，**排除治疗性如肿瘤疫苗**）

覆盖所有使用 CpG 佐剂的**预防性疫苗**，包括但不限于：

| 类别 | 疫苗/病原体 |
|------|------------|
| 乙肝疫苗 | HBV（Heplisav-B、国产重组乙肝疫苗 CpG+铝 等） |
| 新冠疫苗 | SARS-CoV-2（SCB-2019/SPECTRA、ZR202-CoV 等） |
| 炭疽疫苗 | 炭疽杆菌（AV7909） |
| 疟疾疫苗 | 疟原虫（BK-SE36/CpG 等早期研究） |
| 钩虫疫苗 | 钩虫（Na-GST-1/CpG 等早期研究） |
| 流感疫苗 | 流感病毒（H5N1/CpG 等） |
| 鼠疫疫苗 | 鼠疫耶尔森菌（rF1V/CpG 等） |
| 带状疱疹疫苗 | VZV（Z-1018、国产管线等） |
| HPV 疫苗 | 人乳头瘤病毒（如仅临床前/无人体数据则不列入） |
| 狂犬疫苗 | 狂犬病毒（如仅临床前/无人体数据则不列入） |

### 2.2 双平台注册编号定位

| 平台 | 编号体系 | 定位要求 |
|------|---------|---------|
| **FDA 域** — ClinicalTrials.gov | **NCT 号** | 精确到具体试验编号，核验试验状态与安全性结果 |
| **NMPA 域** — 中国药物临床试验登记与信息公示平台（Chinadrugtrials.org.cn） | **CTR 号** | 精确到具体登记号（如 CTR2020xxxx） |
| **中国临床试验注册中心**（ChiCTR.org.cn） | **ChiCTR 号** | 精确到具体注册号（如 ChiCTR2500108408）；CTR 未覆盖的国内试验在此补充 |

> 注：CTR 平台 2013/2014 年才建立，更早的试验（如 2016 年乙肝 I 期）可能无 CTR/ChiCTR 号，此时登记编号填"无（平台建立前开展）"，以 PMID/DOI 作为溯源主键。

### 2.3 文献筛选规则

- 同一疫苗/产品有多项临床试验与文献时，**优先选择样本量更大的核心临床试验**及对应文献（提升数据代表性）
- 文献类型优先级：核心试验发表论文（II/III 期或上市后汇总分析）> 其他原始文献 > 综述（综述仅作背景与 AESI 佐证，不作安全性数值来源）

### 2.4 纳入/排除规则（数据缺口处理，沿用 v2.0）

| 情形 | 处理 |
|------|------|
| 安全性数据已公开（文献/注册平台结果） | ✅ 列入总表，完整量化数据 |
| 临床试验信息可查（NCT/CTR/ChiCTR 可定位、设计已知）、安全性数据未公开 | ✅ 列入总表，试验信息照实填写，安全性数据列填"**未公开（进行中）**" |
| 临床试验信息未公开 **且** 安全性数据未公开 | ❌ 不列入表格，文末一句话带过 |
| 仅临床前研究、无人体临床试验 | ❌ 不列入 |

### 3.2 五列表头与内容要求

| # | 列表头 | 内容要求 |
|---|--------|---------|
| 1 | **疫苗名称 & 适应症** | 疫苗/产品名称（含研发代号）+ **佐剂类型**（如 CpG 1018、CpG 7909、CpG ODN）；并**明确列出对应的预防适应症**（疾病/病原体） |
| 2 | **注册平台 & 编号** | 注册平台（FDA/NMPA/ChiCTR）+ 对应 **NCT 号 / CTR 号 / ChiCTR 号**（可并列多个） |
| 3 | **临床试验基本信息** | 该疫苗**核心试验**的：试验分期 / 整体设计（随机、双盲、安慰剂对照、多中心等）/ 样本量（总例数）/ 试验分组（各干预组与对照组）/ 研究终点（主要+关键次要） |
| 4 | **安全性数据汇总（核心列）** | 见下方 3.3 专项规则；**动态分类排版**，尊重复原文献分类逻辑，单元格内层次化文本排版 |
| 5 | **核心参考文献** | 提供安全性数值来源的**核心文献**：作者/期刊/年份 + **PMID + DOI + 原文链接**（三者尽量齐全，至少 PMID 或 DOI 之一） |

### 3.3 【安全性数据汇总】列专项规则

**（1）动态分类排版（不强制"局部/全身"）**

- 以**原文核心文献的实际分类逻辑**为准组织单元格内容，常见分类方式：
  - "局部 vs 全身"
  - "征集性 vs 非征集性"
  - "疫苗相关 vs 疫苗无关"
  - 或按原文自定义分层
- 单元格内**层次化文本排版**：分类标题 + 缩进列表，每项反应一行，格式示例：

```
【征集性局部 AE】(AE)
· 注射部位疼痛 66.67%（32/48）
· 注射部位红斑 xx%（x/x）
【征集性全身 AE】(AE)
· 发热 22.2%（P=0.556 vs 对照）
· 头痛 xx%（x/x）
【SAE】0 例（0%）
【AESI】无
```

**（2）具体数值要求（硬性）**

- **禁止**仅用"与安慰剂相似""安全性良好""总体耐受"等定性描述代替数值
- 必须提取具体**发生率（百分比）**，尽可能含**分子/分母**（例数/总数）；原文确实未报道时填"原文未报道"

**（3）具体名称要求**

- 必须列出已知的具体反应名称：注射部位疼痛、红斑、肿胀、硬结、发热、头痛、肌痛、疲劳、恶心等（按原文实际报告为准）

**（4）AE 与 ADR 的区分与标注（硬性）**

- 数据**优先取用 ADR**（不良反应，判定与疫苗接种相关）
- 若文献未区分或仅报告 AE（不良事件），则使用 **AE** 替代
- **每一项具体数据的末尾，必须明确标注 (AE) 或 (ADR)**，让读者清晰区分因果定性

**（5）严重安全性数据（必须包含）**

- **SAE（严重不良事件）**：具体发生例数 + 发生率（%），及因果判定（如"0 例，无疫苗相关死亡"）
- **SADR（严重不良反应）**：如有则单列
- **AESI（特殊关注不良事件）**：如免疫介导疾病、输尿管结石等，具体例数 + 发生率（%）；无则注明"无"

**（6）专业术语**

- 中英文字段专业术语准确规范（如局部/全身 = Local/Systemic，征集性 = Solicited，非征集性 = Unsolicited）
