# 防火墙团队 — 交叉验证决策表 (Decision Matrix)

本决策表详细说明了“防火墙团队”在汇总 **中心实验室 (qPCR)** 和 **专家委员会 (EAC)** 的结果后，如何依据“判定章程”得出最终的诊断结论。

> **核心原则**：
> 当 EAC 判定结果与 qPCR 结果不一致时，**以 qPCR 结果为病例判定的依据**。
> 仅当无皮损样本或 qPCR 结果无法判定时，才采用 EAC 的临床诊断结论。

---

## 第一阶段：盲评与实验室结果交叉验证

| qPCR 检测结果 | EAC 第一阶段盲评结果 | 防火墙团队最终判定结论 | 判定依据/说明 |
| :--- | :--- | :--- | :--- |
| 🔴 **阳性**<br>*(≥1个样本阳性)* | **是** *(符合带状疱疹)* | ✅ **实验室确诊病例** | qPCR 阳性为金标准，直接确诊 |
| 🔴 **阳性** | **否** *(不符合)* | ✅ **实验室确诊病例** | qPCR 结果优先于 EAC 判定 |
| 🔵 **真阴性**<br>*(内参+，靶基因-)* | **是** *(符合带状疱疹)* | ❌ **非带状疱疹排除** | qPCR 结果优先于 EAC 判定 |
| 🔵 **真阴性** | **否** *(不符合)* | ❌ **非带状疱疹排除** | 实验室与临床意见一致排除 |
| ⚪ **无法判定 / 无样本**<br>*(内参-且靶基因-)* | **否** *(不符合)* | ❌ **非带状疱疹排除** | 缺乏实验室依据且临床不支持 |
| ⚪ **无法判定 / 无样本** | **是** *(符合带状疱疹)* | 🔄 **进入第二阶段复判** | 实验室无结论但临床支持，防火墙团队汇总该情况交由 EAC 重新审视 |

---

## 第二阶段：EAC 复判（仅针对第一阶段最后一种情况）

防火墙团队将“qPCR无法判定/无结果”的信息汇总给 EAC，由 EAC 结合该客观信息对病例进行第二阶段复判：

| EAC 第二阶段复判结果 | 最终判定结论 | 归类说明 |
| :--- | :--- | :--- |
| **仍符合**带状疱疹 | 🟣 **临床诊断确认病例** | 最终确诊（但属于临床确诊，非实验室确诊） |
| 改判为 **不符合** | ❌ **非带状疱疹排除** | 被排除的疑似病例 |
| **无法判定** | ⬜ **不能确诊** | 证据均不足，列为不能确诊病例 |

---

### 💡 最终确诊病例统计口径
**带状疱疹确诊病例总数** = **✅ 实验室确诊病例** + **🟣 临床诊断确认病例**
