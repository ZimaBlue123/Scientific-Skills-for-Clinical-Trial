## 三、数据呈现形式：三模块综合表格

### 3.1 表格总体排版规格（Word 内）

| 项目 | 规格 |
|------|------|
| 表型 | 网格表（全框线），表头底纹浅灰、加粗 |
| 字号 | 表头 9-10pt 加粗；正文 9pt（数据密集时 8.5pt） |
| 分块 | 按**地域**分两大节：国外（国际上市产品/试验）→ 国内（已发表试验 → 进行中试验）；节内按疫苗类型排布 |
| 数据标注 | 关键数值加粗；每格数据后标注来源编号 [1][2]…，与模块三对应 |
| 缺项处理 | 无数据填 "—"；未公开填 "未公开（进行中）" |

### 3.2 【模块一】临床试验基本信息表

| 字段 | 说明 |
|------|------|
| 试验标识 | NCT 号 / CTR 号（可并列） |
| 疫苗名称 | 疫苗/产品名称（含研发代号） |
| 适应症 | 明确标注所针对的疾病/病原体 |
| 地域 | 国际 / 国内 |
| 试验分期 | Phase 1 / 2 / 3 / 上市产品 |
| 整体设计 | 随机、双盲、安慰剂对照、多中心等 |
| 样本量 | 总受试者人数（例） |
| 试验分组 | 各干预组与对照组设计（组名 + 样本量） |
| 研究终点 | 主要终点 + 关键次要终点 |

### 3.3 【模块二】核心安全性数据表（量化）

| 字段 | 说明 |
|------|------|
| 试验标识 | NCT / CTR 号（与模块一对应） |
| 局部 AE/ADR | 具体反应名称（疼痛、红肿、硬结等）+ **具体发生率（%）** |
| 全身 AE/ADR | 具体反应名称（发热、疲劳、肌痛、头痛等）+ **具体发生率（%）** |
| 数据性质 | 标注该列数据来源：**ADR**（与疫苗因果相关）或 **AE**（不良事件）——优先 ADR，文献无 ADR 数据时用 AE 替代并注明 |
| SAE / SADR | 具体发生例数 + 发生率（%）及因果判定 |
| AESI | 特殊关注不良事件（潜在免疫介导疾病）具体例数 + 发生率（%） |

> **硬性要求**:
> ① 所有安全性数据**必须来源于文献原文的仔细阅读与提取**，必须包含具体数值（百分比 + 分子/分母）
> ② **不得以"与对照组相似""安全性良好"等定性描述代替数值**；原文确实未报道时，填"原文未报道"
> ③ 数据未公开的试验（进行中）整列填"未公开（进行中）"

### 3.4 【模块三】详细参考文献表

| 字段 | 说明 |
|------|------|
| 试验标识 | NCT / CTR 号 |
| 文献标题 | 核心文献全名（含作者、期刊、年份） |
| DOI | 数字化对象标识符 |
| PMID | PubMed 标识号 |
| 原文链接 | 可点击的原始网址（期刊页 / ClinicalTrials.gov 页 / 注册平台页） |

> 模块二每条数值以 [n] 形式标注来源，与模块三行一一对应，确保可溯源。
